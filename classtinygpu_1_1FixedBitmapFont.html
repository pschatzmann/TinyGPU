Detailed Description

template<uint8_t Width, uint8_t Height, typename RowT, typename RGB_T = RGB565>
class tinygpu::FixedBitmapFont< Width, Height, RowT, RGB_T >

Fixed-size bitmap font backed by a caller-supplied glyph table.

Template Parameters
WidthGlyph width in pixels.
HeightGlyph height in pixels.
RowTUnsigned integer type used to store one glyph row. Only the Width most significant bits of each row are used (bit Width-1 is the left-most pixel), mirroring the bit order used by BitmapFont.
RGB_TThe pixel color type. Can be RGB565, RGB666, RGB888, etc.

Concrete fonts (e.g. converted from vendor font tables) subclass this and pass their own glyph table to the constructor. Only a contiguous ASCII range starting at firstChar is supported; any code point outside that range falls back to the glyph for '?'.
