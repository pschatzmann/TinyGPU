Detailed Description

Common interface for a board that bundles a display, an optional touch controller, an I2S pin assignment, and an LED pin assignment behind one begin() call. All boards implementing this use RGB565 panels, so display() is pinned to that color type here (each concrete board still returns its own driver subclass via a covariant return type).
