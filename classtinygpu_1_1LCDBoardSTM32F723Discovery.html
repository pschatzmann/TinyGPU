Detailed Description

"STM32F723E-Discovery" - on-board 240x240 ST7789H2 LCD (FMC) + FT6x06/FT3x67 capacitive touch, via the stm32f723-disco library.

No I2S/LED pin assignment here: the board's audio codec is driven over SAI (see the library's own Audio.h), not I2S, so i2s() reports "not present" (every field -1); LED_RED/LED_GREEN/USER_BTN are ordinary Arduino digital pins defined by the STM32duino board variant itself (see the stm32f723-disco umbrella header's doc comment) rather than pins this class would need to track, so led() likewise reports "not present".
