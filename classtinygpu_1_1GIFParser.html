Detailed Description

template<typename RGB_T = RGB565>
class tinygpu::GIFParser< RGB_T >

GIF decoder for TinyGPU surfaces (GIF87a and GIF89a).

Decodes the first image of a GIF file held in memory into an ISurface. The surface is resized to the logical screen of the GIF. The area outside the first image, and its transparent pixels, get the background colour. Local and global palettes and interlaced images are supported. Animations show their first frame only.

The compressed data of the image is kept in memory while decoding.

Surface<RGB565> image(1, 1, FontRGB565);
GIFParser<RGB565> parser(image);
if (parser.decode(data, size)) { ... }
