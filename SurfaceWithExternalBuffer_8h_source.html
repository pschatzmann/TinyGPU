24 * @brief In-memory bitmap surface with basic 2D drawing and text rendering.
25 *
26 * @tparam RGB_T The pixel color type. Can be RGB565, RGB666, RGB888, etc.
27 *
28 * The class stores pixel data in a contiguous buffer and provides helpers for

31 * Example usage:
32 * Surface<RGB565> surf565(240, 320);
