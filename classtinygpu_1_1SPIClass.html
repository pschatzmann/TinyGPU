Detailed Description

ESP-IDF driver/spi_master.h-backed stand-in for Arduino's SPIClass, covering exactly what this library's SPI-based display/touch drivers call: beginTransaction()/endTransaction() and both transfer() overloads (single byte, and in-place full-duplex buffer). Chip select is NOT driven by this class - callers here always toggle their own CS pin via digitalWrite() around each transfer, the same division of responsibility Arduino's own SPIClass uses - so the underlying esp_lcd/spi_master device is configured with no CS pin of its own (spics_io_num = -1).
