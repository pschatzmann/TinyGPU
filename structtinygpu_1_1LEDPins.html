Detailed Description

LED pin assignment for a board's status LED, if any. Boards in this file use one of two shapes: a single-wire addressable LED (WS2812 and similar - set single) or a discrete 3-pin RGB LED (set r/g/b and activeLow). -1 means "no pin of that kind on this board" - a board with neither leaves every field at -1.
