Detailed Description

template<typename RGB_T = RGB565, typename SurfaceT = Surface<RGB_T>>
struct tinygpu::SpriteInfoWithoutBackground< RGB_T, SurfaceT >

A specialized SpriteInfo that does not save the background pixels.

This is useful for sprites that do not need to restore the background, such as those that are always drawn on a solid color or when the background is managed separately.
