Detailed Description

Desktop SDL2 window standing in for a physical LCD board. Window size is set at construction time (default 320x240) since - unlike the hardware boards in LCDBoardsESP32.h - there is no fixed panel to match.

The left mouse button stands in for a finger (see TouchDriverSDL). There is no backlight/I2S/LED hardware on this backend, so i2s()/led() report "not present" (every field -1) and backlightPin() is -1.
