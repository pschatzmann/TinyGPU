Detailed Description

Platform-independent touch driver interface: the Point/ CalibrationData/Rotation types, the TouchDriver base class (calibration storage, raw-to-logical coordinate mapping) and nothing else - this file has no dependency on Arduino.h or any bus library, so including it (e.g. transitively via TinyGPU.h) never requires linking against an Arduino core.

Concrete controller drivers (XPT2046, FT6236/FT6206, CST816S, GT911), which do need Arduino.h/SPI.h/Wire.h, live in the separate TouchDriverArduino.h - include that explicitly to use one of them.
