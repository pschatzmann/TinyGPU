Detailed Description

template<typename RGB_T = RGB565>
class tinygpu::PNGParser< RGB_T >

PNG decoder for TinyGPU surfaces.

Decodes a PNG file held in memory into an ISurface, which is resized to the image size. All colour types (grayscale, RGB, palette, with or without alpha) and bit depths 1, 2, 4, 8 and 16 are supported. Transparent pixels are mixed with the background colour. Interlaced (Adam7) images are not supported.

The decoded data is kept in memory while decoding (the decompressed image), so the parser needs about (height * width * channels) bytes of RAM.

Surface<RGB565> image(1, 1, FontRGB565);
PNGParser<RGB565> parser(image);
if (parser.decode(data, size)) { ... drawSprite(..., image) ... }
